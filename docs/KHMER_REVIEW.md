# Khmer wording to review

All Khmer text is in `i18n/locales/km.json`. These are the game's own words, chosen for a farm in a
Khmer village; a native speaker should check them before a wider release.

| Key | Khmer | Meaning |
|---|---|---|
| `app.title` | ចំការ | Chamkar: the farm (field, plantation) |
| `items.*` | ពងមាន់, ពងទា, ទឹកដោះគោ, នំខេក, ពងទាប្រៃ, ទឹកដោះគោជូរ, បង្អែម | eggs, duck eggs, milk, cakes, salted eggs, yogurt, desserts |
| `news.bakery.name` etc. | ហាងនំ, ពាងអំបិល, រោងទឹកដោះគោ, តូបបង្អែម | bakery, salt jars, dairy, dessert stall |
| barn | ជង្រុក | granary on stilts, used for the barn |
| pen | ក្រោល | the animals' pen |
| tuk-tuk | រ៉ឺម៉ក | remorque (the Cambodian tuk-tuk) |
| coins | កាក់ | coins |
| `goals.*` | ប្រមូល{name} {n}, មាន{name} {n} ក្បាល, រកបាន {n} កាក់ នៅផ្សារ | the order's lines |
| `story.*` | Ta speaks to Srey as ចៅ and of himself as តា; Sva speaks as ខ្ញុំ | the story's voices |
| `kinds.raid` | ស្វាវាយលុក | "monkey raid" |
